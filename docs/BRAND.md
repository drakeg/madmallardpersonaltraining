# Mad Mallard Personal Training — brand system

Creative Studio redesign: athletic editorial direction, warm ivory #f5f1e8, mallard green #102d24, orange #ef780c, olive #647c37 and charcoal #202522. Dark orange #a23f00 for small text on light backgrounds. Display: Arial Narrow/Aptos Display/Impact with system fallback; body: system UI. No redistributed font files or external font requests.

The shield mallard SVG and gym equipment SVG are original editable vector artwork authored for this preview. The mark is a provisional implementation, not an approved final logo. Earlier generated photo and mockup are design references; their raster files are not included in this commit. No actual clients or outcomes are depicted. Retain the static stack; reject React/Tailwind component libraries for now because the present site is dependency-free. Shared tokens live in site/assets/brand/theme.css and can be reused by future client/admin pages.
